数组
    数组放在一块连续的内存空间，二维的话就是先列后行
    下标从0开始，最后一个下标为数组长度-1
    访问：数组名[下标]
    一维数组
        定义方式（语法）：
            数组类型 数组名[数组长度];
            数组类型 数组名[数组长度] = {值1,值2,……};
            数组类型 数组名[] = {值1,值2,……};
        
        一维数组名
            sizeof统计整个数组的内存长度，指针默认为8字节
                语法：sizeof(数组名)
            直接访问数组名访问的是地址，地址为第一位的地址
            数组名是常量
    二维数组
        定义方式（语法）：
            数组类型 数组名[行数][列数];
            数组类型 数组名[行数][列数] =
            {
                {数据1,数据2,……},
                {数据1,数据2,……},
                ……,
                {数据1,数据2,……}
            };
            数组类型 数组名[行数][列数] = {数据1,数据2,数据3,数据4,……};
            数组类型 数组名[][列数] = {数据1,数据2,数据3,数据4,……};
                行数可以省，列数不行
        二维数组名
            某行：数组名[行数]
                sizeof(数组名[行数])访问的是该行的内存长度
                直接访问某行访问的是该行第一位的地址
        求行数与列数exp：
            行：sizeof(arr) / sizeof(arr[0])
            列：sizeof(arr[0]) / sizeof(arr[0][0])

函数
    作用：将一段经常使用的代码进行封装
    定义：
        返回值类型
        函数名
        形参列表（可省）
            若是数组写：数组名[]，传入的是指针
        函数体语句
        return表达式
    语法：
        返回值类型 函数名(形参1,形参2,……)
        {
            函数体语句

            return表达式
        }
    调用：
        语法：函数名(实参1,实参2,……)
        当函数调用时，实参的 值 会传递给形参
    void意为无，当返回值类型是void是无需return表达式
    当我们做值传递时，形参发生改变，不会影响实参
        exp:
            void f(int a,int b)
            {
                a = 10;b = 20;
                cout << a << endl << b << endl;
            }
            int main()
            {
                int a = 1;
                int b = 2;
                f(a,b);//实际上这个是废的，利用值传递永远无法改变实参
                cout << a << endl << b << endl;

                system("pause");
                
                return 0;
            }
            //输出：10 20 1 2
    声明：
        作用：提前告诉编译器函数的存在，防止用函数时函数还未定义
        声明可以有多次，定义只能有一次
    函数的分文件编写：
        1、创建.h头文件
        2、在头文件中写函数声明和其对应源文件的头文件
        3、创建.cpp源文件
        4、在源文件中写函数定义，include其头文件
        5、在main文件中include头文件

指针
    作用：存放变量地址，本身也是一个变量
    定义：
        语法：
            数据类型 * 指针变量名;
            指针变量名 = &变量名;
                &为取地址符
    使用：
        解引用：找到指针所存地址对应的变量
            语法：*指针变量名
            *与&是逆运算
                exp: 
                    p 等于 &a
                    *p 等于 a
    内存空间：
        32位操作系统（86）4字节
        64位操作系统（x64x）8字节
            等同于long
    运算：
        +1为向后挪一个指针指向数据类型的内存单位
        exp：
            char * pc;   pc++;// 加 1 字节
            int *  pi;   pi++;// 加 4 字节
            double * pd;  pd++;// 加 8 字节
        注意这和指针变量本身占8字节不矛盾
    空指针：指针变量指向内存中编号为0的空白
        作用：初始化指针变量
        注意：空指针不可访问，0-255是系统内存
        exp：int * p = NULL;
    野指针：指针变量指向非法内存空间
    const修饰指针：
        常量指针
            语法：const 数据类型 * 指针变量名;
            特点：*p是常量，p可以改，*p不能改
        指针常量
            语法：数据类型 * const 指针变量名;
            特点：p是常量，p不可以改，*p可以改
        可以既修饰指针，又修饰常量，这样p和*p都不能改
        记忆：常量（const）指针（*）
    指针和数组
        利用指针访问数组中的元素
        p[i] = *(p + i)
    指针和函数
        地址传递可以修饰实参

结构体
    结构体属于用户自定义类型，允许用户存储不同的数据类型
    定义：
        语法：
            struct 结构体名
            {
                数据类型 变量名;//成员1
                数据类型 变量名;//成员2
                ……
            };
    通过结构体创建变量：（struct关键字可以省略）
        方式1：
            语法： 
                struct 结构体名 结构体变量名;
                结构体变量名.成员1 = 具体数值;
                结构体变量名.成员2 = 具体数值;
                ……
        方式2：
            语法：
                struct 结构体名 结构体变量名 = {成员1值，成员2值……};
        方式3：定义结构体时顺便创建变量
            语法：
                struct 结构体名
                {
                    数据类型 变量名;//成员1
                    数据类型 变量名;//成员2
                    ……
                }结构体变量名1,结构体变量名2,……;
    访问变量成员
        结构体变量名.成员名 = 具体数值;（不用写结构体名）
    结构体数组
        创建的语法：（struct关键字可以省略）
            struct 结构体名 结构体数组名[元素个数] = 
            {
                {成员1值，成员2值……}//不知道的可以不写或只初始化
                {成员1值，成员2值……}
                ……
            }
        访问：
            结构体数组名[下标].成员名
    结构体指针
        创建的语法：
            结构体名 * 指针变量名 = &结构体变量名;
        访问结构体变量中的成员
            指针变量名 -> 成员名（不需要*）
    结构体的嵌套
        定义要分开
        访问子结构体变量
            母结构体变量名.子结构体变量名.成员名
    结构体中的const
        使用常量结构体指针，既减少内存空间占用，又确保只读

c++核心编程
    内存分区模型
        代码区
            存放函数体的二进制代码，由操作系统进行管理（exe程序）
            共享、只读
        全局区
            存放全局变量和静态变量以及常量
            数据在程序结束时由操作系统释放
        栈区（通俗理解：局部区）
            由编译器自动分配释放，存放形参和局部变量
                注意：
                    不要返回局部变量的地址，尽管编译器会做一次保留
        堆区
            由程序员分配和释放，若程序员不释放，程序结束时由操作系统回收
            用new开辟堆区内存
                开辟数据类型
                    语法：
                        new 数据类型(变量值) 
                    new函数返回的是该数据类型的指针
                开辟数组
                    语法：
                        new 数据类型[数组长度]
                        new函数返回的是数组的首地址
            用delete释放堆区数据
                语法：
                    delete 地址;
                    delete[] 数组名;
    引用
        作用：
            给变量起别名，指向同一块内存
        本质：
            一个指针常量，但调用时省去解引用
                int &b=a 等于 int * const p=a;
                b=10 等于 *p=10
        语法：
            数据类型 &别名=原名;
        注意：
            引用必须初始化
            引用必须引用合法内存空间
            初始化后不可以更改（因为是指针常量，指向不可改）
        引用与函数
            引用做函数参数
                可以使形参修饰实参
                exp：
                    void func(int &a,int &b)//只需修改中这里，其他和值传递一样
                    {
                        ……
                    }
            引用做函数返回值
                不要返回局部变量的引用（局部变量地址会被释放）
                如果函数返回值是引用，函数调用可以作为左值（等号左边）
                exp:
                    int& func()
                    {
                        ……
                        return a;
                    }
        常量引用
            作用：修饰形参，防止误操作（可以完全代替值传递了？）
            exp:
                void func(const int &a)
                {
                    ……
                }
            与值传递异同：
                异：值传递可以修改形参，常量引用的引用传递不可以修改形参
                同：都可以防止实参被修改
    函数提高
        默认参数
            形参可以有默认值
                有默认值的形参依然可以被传入值
                默认参数后若还有参数，必须是默认参数
                若函数的声明和实现只能有一个有默认参数，一般是声明    
        占位参数
            exp:
                void func(int)
            占位参数可以有默认值
                exp:
                    void func(int =10)
        函数重载
            函数可以复用
            条件
                同一作用域
                函数名相同
                函数参数类型或个数或顺序不同
                    const int 和 int 算两种类型
                    默认参数可以不算参数个数
            注意：返回值不同不算条件（机器无法判断）
    类和对象
        封装
            语法： 
                class
                {
                    访问权限：
                    属性 //（成员变量）
                    行为 //（成员函数、成员方法）
                }
                //属性和行为统称为成员
            权限：
                公共权限public：类内可以访问，类外可以访问
                保护权限protected：类内可以访问，类外不可以访问
                私有权限private：类内可以访问，类外不可以访问
            struct和class的区别：
                唯一：默认权限不同
                    struct默认公共
                    class默认私有
            成员属性设置为私有
                写取：set_函数
                读取：get_函数
                好处：
                    可以自己控制读写权限
                    对于写可以检测数据有效性（set_函数）
        对象的初始化和清理
            构造函数和析构函数
                构造函数
                    语法：类名(){}
                    特点：
                        没有返回值，也不用写void
                        可以有参数，可以发生函数重载
                        创建对象时，构造函数会自动调用，而且只调用一次
                        可以不写构造函数，那就调用系统的构造函数，但它是空实现（{}里面什么都没有）
                    分类：
                        按参数分：
                            有参构造
                            无参构造
                        按类型分：
                            普通构造
                            拷贝构造
                                exp:
                                    person(const person &p){age=p.age;}
                    调用：
                        括号法
                            exp:
                                person p;//默认构造函数调用
                                person p(10);//有参构造函数调用
                                person p(p2);//拷贝构造函数调用
                        显示法

                        隐式转换法
                析构函数
                    语法：~类名(){}
                    没有返回值，也不用写void
                    不能有参数，不能发生重载
                    销毁对象时，析构函数会自动调用，而且只调用一次
                    可以不写析构函数，那就调用系统的析构函数，但它是空实现（{}里面什么都没有）
